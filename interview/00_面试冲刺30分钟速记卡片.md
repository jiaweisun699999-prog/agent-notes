## 核心公式与计算速记卡片

### 1. Self-Attention 缩放点积公式
$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$
> **口诀**：点积算相似，除以 $\sqrt{d_k}$ 防梯度消失；Softmax 转概率，加权求和出 Context。

### 2. LoRA 低秩微调公式
$$h = W_0 x + \Delta W x = W_0 x + \frac{\alpha}{r} (B \cdot A) x$$
> **口诀**：大矩阵不更新，降维分解 $B \cdot A$；$A$ 高斯初始化，$B$ 归零，$r$ 远小于维数 $d$。

### 3. KV Cache 显存大小计算公式
$$\text{KV Cache Size (Bytes)} = 4 \times n_{\text{layers}} \times d_{\text{model}} \times s \times b$$
> **例题**：Llama-3 8B ($32 \text{ 层}, 4096 \text{ 维}$)，输入 4096 Token，Batch=4，占用约为 **8.59 GB**。

### 4. RRF (Reciprocal Rank Fusion) 混合检索融合公式
$$RRF\_Score(d) = \sum_{m \in M} \frac{1}{k + r_m(d)}$$
> **口诀**：不看绝对得分看排名，排名越靠前分越高，倒数叠加无缝合并 Dense 和 BM25。

## 🔥 核心概念极速对比表

| 对比维度 | 方案 A | 方案 B | 结论 / 生产选型推荐 |
| :--- | :--- | :--- | :--- |
| **序列模型** | RNN / LSTM (串行递推) | Transformer (全局自注意力) | 主流选用 **Transformer**（彻底解决 RNN 不可并行与长距离梯度消失瓶颈） |
| **CNN 卷积池化** | 卷积 (局部连接+权值共享) | 池化 (降维+平移不变性) | **卷积**提取局部特征，**池化**降维去噪并防过拟合 |
| **位置编码** | 绝对正弦 (Sinusoidal) | 旋转位置编码 (RoPE) | 主流选用 **RoPE**（保持相对位置复数内积，易于长文本外推） |
| **归一化** | Post-LN | Pre-LN / RMSNorm | 主流选用 **Pre-LN / RMSNorm**（残差主干无阻碍，训练超深模型不发散） |
| **注意力头** | MHA (多头) | GQA (分组头) / MLA (DeepSeek) | **GQA** 折中性价比高；**MLA** 隐空间压缩，KV Cache 降至极低且性能无损 |
| **偏好对齐** | RLHF (PPO需4个模型) | DPO / GRPO (无Critic模型) | **DPO** 极简无奖励模型；**GRPO** (DeepSeek-R1) 组内相对奖励，省显存 |
| **GraphRAG** | Vector RAG (碎片匹配) | GraphRAG (实体图谱+社区摘要) | 局部检索选 **Vector RAG**；全局总结与多跳推理选 **GraphRAG** |
| **大模型 Agent** | LangChain AgentExecutor | LangGraph StateGraph | 复杂系统首选 **LangGraph**（状态显式图控制、支持循环、中断与 Time-travel） |
| **Graph 记忆** | Checkpointer (快照) | Store (长期库) | **Checkpointer** 负责单 Thread 历史快照；**Store** 负责跨 Session 用户偏好 |
| **向量检索** | HNSW (分层图) | IVFFlat (倒排聚类) | 追求高召回与极速首选 **HNSW**；海量数据且 RAM 有限选 **IVFFlat** |

## 💻 必考高频代码骨架 (15 秒盲打)

### 1. Python 线程安全单例模式 (Double-Checked Locking)
```python
import threading

class Singleton:
    _instance = None
    _lock = threading.Lock()

    def __new__(cls, *args, **kwargs):
        if cls._instance is None:
            with cls._lock:
                if cls._instance is None:
                    cls._instance = super().__new__(cls)
        return cls._instance
```

### 3. LangGraph 状态图框架骨架
```python
from typing import Annotated, TypedDict
from langgraph.graph import StateGraph, START, END
from langgraph.graph.message import add_messages

class State(TypedDict):
    messages: Annotated[list, add_messages]

def chatbot_node(state: State):
    return {"messages": ["Agent Response"]}

builder = StateGraph(State)
builder.add_node("chatbot", chatbot_node)
builder.add_edge(START, "chatbot")
builder.add_edge("chatbot", END)
graph = builder.compile()
```
